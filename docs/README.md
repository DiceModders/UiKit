# Documentation

Start with the [main README](../README.md) for installation, examples and the public API.

Internal and contributor documentation:

- [Architecture](ARCHITECTURE.md) — runtime, scopes, lifecycle, event model, assets, layers and input internals.
- [Native integrations](NATIVE.md) — game hooks, native handle lifecycle, Settings, scoreboard and Rules internals.
